# SANDRAJCARS - Car Management System

A simple **Car Database Management System** built using Python and MySQL.

## Features

- Add new car records
- Update car details
- Delete car records
- Display all car records
- MySQL database storage
- Simple command-line menu

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python

## Database Structure

The program creates a database named `SANDRAJCARS` and a table named `ROYALCARS`.

The table contains:

| Column | Data Type |
|--------|-----------|
| SNO | Integer |
| CNAME | Varchar |
| COMPANY | Varchar |
| PRICE | Integer |
